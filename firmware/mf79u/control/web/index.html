SMS REST API

Use the modem administrator password with HTTP Basic authentication. Username: admin.

Authorization: Basic <base64(admin:password)>

Header authentication needs no cookie or CSRF token. JSON requests use Content-Type: application/json.

Read messages
GET /api/v1/sms/messages?storage=modem
GET /api/v1/sms/messages?storage=sim
Returns messages, capacity and storage. Reading does not mark messages as read.
number: decoded phone number or sender ID; local numbers are preserved.
date: ISO 8601 with timezone, or null if unknown.
direction: incoming (tags 0/1), outgoing (tags 2/3), draft (tag 4), or unknown.
Original vendor fields remain in rawNumber, rawDate and tag.
{"id":"17","number":"+123456789",
 "date":"2026-10-07T18:04:05+03:00",
 "direction":"incoming","tag":"0","text":"Hello"}
Send SMS
POST /api/v1/sms/messages
{"number": "+123456789", "text": "Hello"}
Unicode supported, 1–670 characters. VoWiFi only uses SMSoIP via the selected Wi-Fi or USB internet connection and never falls back to cellular SMS. Incoming IMS messages appear in Modem memory. SIM charges apply.
Delete SMS
DELETE /api/v1/sms/messages/17
Or bulk DELETE /api/v1/sms/messages:
{"ids": ["17", "18"]}
Use IDs returned by the message list. Up to 100 IDs.

Example (curl prompts for the password):

curl -u admin 'http://192.168.0.1/api/v1/sms/messages?storage=modem'

Successful send/delete returns {"ok":true}. Errors return {"error":"..."}: 400 invalid request, 401 authentication failed, 403 cookie/CSRF rejected, 428 ZTE session unavailable, 502 modem operation failed. If completion is uncertain, check the message list before retrying.

Telegram SMS

New incoming SMS from modem memory, SIM and IMS are sent as sender number, a new line, then message text. Existing messages are skipped on first setup. Deletion happens only after Telegram confirms delivery.

2.4 GHz · WPA2-Personal or Open. Enter a hidden SSID manually. Scanning briefly interrupts an active hotspot.

The IP address, gateway and DNS are obtained automatically (DHCP).

Save to connect or switch mode. Confirm within 90 seconds; failed connections restore the previous network settings.

USB and Wi-Fi network

These settings apply to both USB Ethernet and Wi-Fi hotspot clients. They share the same LAN and DHCP server.

Clients must reconnect or renew their DHCP lease to receive changes. Clients with a manual IP configuration must be updated manually. LTE data off still blocks mobile internet.

Confirm network changes within 90 seconds, otherwise they roll back. USB recovery remains available at 192.168.0.1. After changing the gateway, open the new address to confirm access.

SSH provides administrator shell access from USB and Wi-Fi LAN only. It is blocked on cellular interfaces. SSH uses a separate password.

12–128 printable ASCII characters. Leave both fields blank to keep the saved password. Disabling SSH closes active SSH sessions.

The extended BusyBox shell includes vi, awk, find, tar, nc, ip and checksum tools. The factory BusyBox remains available.
